# Student-Information-System
Варіант 10 - Система обліку студентів.

Опис сутностей:
Консольна програма для оцінювання успішності студента. Вона приймає такі вхідні дані (ПІБ, ID, рік вступу, курс, електрона пошта, середній бал, навчається студент на бюджеті та статус степендії) та визначає поточний рівень успішності за шкалою від "Мінімальної успішності" до "Максимальне нарахування".

### Factory Method (Рефакторинг створення об'єктів)
**Проблема**
Логіка створення об'єкта `Student` була розкидана по коду. Клієнтський клас (`StudentAccounting`) самостійно приймав рішення про те, чи є студент бюджетником і чи має він стипендію на основі введених даних. Це порушувало принцип єдиної відповідальності (SRP), оскільки клас, відповідальний за ввід/вивід, також містив бізнес-логіку.

**Рішення**
Створено клас `StudentFactory` з методом `createStudent`. Завдяки цьому тепер: 
1. Валідація даних (ПІБ, бал, курс) інкапсульована всередині фабрики (принцип Fail-Fast).
2. Бізнес-логіка розрахунку права на стипендію (з урахуванням типу навчання, боргів та пільгових категорій) перенесена у фабрику.
3. Клієнтський код лише збирає "сирі" факти від користувача і передає їх фабриці, отримуючи назад повністю валідний і налаштований об'єкт.

**Результат**
Додавання нового типу (наприклад, `GRANT`) тепер вимагає змін лише в одному місці — всередині `StudentFactory`. Клієнтський код залишається незмінним, що відповідає принципу Open/Close (OCP).


Інструкція запуску програми:

Вимоги: JDK 25 

Запуск Windows: 
Спосіб 1 (Компіляція та запуск)
1. Зберігаємо файл, назва файлу.java. ```.java``` обов'язкове для роботи з Java
2. Відкрити провідник , знайти папку де знаходиться наш файл та не виходячи з папки в адресному рядку ввести команду 

        cmd
   
3. В термінал ввести команду для компіляції коду

        javac назва файлу.java

4. Після виконання команди ввести наступну 

        java назва файлу


Спосіб 2 (Файл run.bat)
1. Створити текстовий файл і перейменувати його в run.but
2. В файл написати код який буде відповідати за запуск програми. В наступному коді відувається компіляція та запукс.

          @echo off
          echo [1/2] Компіляція коду...
          java назва файлу.java   

          if %errorlevel% noq 0 (
            echo Помилка компіляції
            pause
            exit /b %errorlevel%
          )

          echo [2/2] Запуск програми...
          java назва файлу

          pause



Запуск Linux/macOS:
Спосіб 1 (Компіляція та запуск)
1. Зберігаємо файл, наприклад: назва файлу.java. Розширення ```.java``` є обов'язковим для роботи з Java.
2. Відкрити термінал і перейти в папку з файлом за допомогою команди. В команді потрібно ввести шлях до папки де знаходиться файл з кодом:

        cd /шлях/до/папки/з/програмою

3. В терміналі ввести команду для компіляції коду:

       javac назва файлу.java

4. Після успішної компіляції ввести наступну команду:

           java назва файлу

           
Спосіб 2 (Файл run.sh)
1. Створити текстовий файл і перейменувати його в run.sh
2. У файл написати код, який відповідає за компіляцію та запуск. Важливо додати "shebang" ```#!/usr/bin/env bash``` на початку.

          #!/usr/bin/env bash
          echo "[1/2] Компіляція коду..."
          javaс назва файлу.java

           if [ $? -ne 0 ]; then
              echo Помилка компіляції
              exit 1
           fi

          echo "[2/2] Запуск програми..."
          java назва файлу

3. Для того щоб надати права на виконання через термінал потрібно ввести таку команду(робиться 1 раз):

        chmod +x run.sh

4. Запуск скрипта через команду:

        ./run.sh
